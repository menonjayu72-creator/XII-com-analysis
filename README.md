# Result Analyzer – XI Commerce B 2025–26

Single-page app (HTML, CSS, JavaScript) that analyses student marks.

## Run locally
Open `index.html` in any browser. No install or internet needed.

## Host on GitHub Pages
1. Upload `index.html` (and this README) to the root of a repository.
2. Settings → Pages → Source: `main` branch, `/ (root)`.
3. Open `https://<username>.github.io/<repo>/`.

Note: the file contains student names and marks. Keep the repository private if the data should not be public.
